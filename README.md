# Shahi - Shipment Management Dashboard

A modern, real-time logistics and shipment management dashboard built with React, TypeScript, and Supabase.

## Features

- **Trip Management** - Create, read, update, and delete shipment trips
- **Real-time Dashboard** - Monitor shipment status and logistics operations
- **Advanced Analytics** - Visual insights with charts and KPI metrics
- **Google Sheets Integration** - Sync data with Google Sheets via Supabase
- **Responsive Design** - Mobile, tablet, and desktop optimized
- **Dark Theme** - Modern glassmorphic UI design

## Tech Stack

- React 18 + TypeScript
- Vite (Build Tool)
- Tailwind CSS + shadcn/ui
- Supabase (Backend)
- React Query (State Management)
- Recharts (Analytics)

## Getting Started

```bash
npm install
npm run dev
```
